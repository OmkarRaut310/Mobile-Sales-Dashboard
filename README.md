# Mobile-Sales-Dashboard

1. 📊 Mobile Sales Analytics Dashboard  

## 📝 Short Description / Purpose  
An advanced **Power BI dashboard** designed to analyze **Motorola mobile sales performance** across India. It highlights brand comparisons, customer ratings, payment preferences, and city‑wise sales distribution for better business insights.  

2. ⚙️ Tech Stack  
- **Power BI** → Data visualization & reporting  
- **DAX** → Custom measures & KPIs  
- **Power Query** → Data transformation  
- **Excel / CSV** → Data source integration  

3. 📂 Data Source  
- Mobile sales dataset including:  
  - Transaction records  
  - Payment methods (UPI, Debit Card, Credit Card, Cash)  
  - Customer ratings (2–5 stars)  
  - Brand & model details  
  - City‑wise sales data  

 4. 🌟 Features / Highlights  
- **Top KPIs**:  
  - Total Sales: 769M  
  - Total Quantity: 19K  
  - Transactions: 4K  
  - Average Sales: 40.11K  

- **Geographical Insights**: Map visualization of sales across cities (Delhi, Mumbai, Bangalore, Chennai, Hyderabad, Kolkata, etc.).  
- **Brand Analysis**: Apple, OnePlus, Samsung, Vivo, Xiaomi sales comparison with quantity & transaction counts.  
- **Customer Ratings**: Distribution of ratings (2–5 stars) and weekday sales performance (e.g., Monday & Friday: 26.4M).  
- **Payment Method Breakdown**: UPI, Debit Card, Credit Card, Cash transaction shares.  
- **Trend Analysis**: Daily sales & quantity trends from January to February.  
- **Model-Level Insights**: Sales by mobile models (iPhone, OnePlus, Galaxy).  

5. 📌 Example Use Case  
A business analyst or sales manager can use this dashboard to:  
- Identify **top-performing brands and cities**.  
- Track **preferred payment methods** among customers.  
- Spot **peak sales days** to plan promotions.  
- Monitor **customer satisfaction** through ratings.
